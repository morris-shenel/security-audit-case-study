# Security Audit Case Study

## Overview

This project documents a security audit conducted for a fictional retail organization as part of the Google Cybersecurity Professional Certificate. The audit evaluated existing security controls, identified compliance gaps, assessed organizational risk, and provided recommendations to improve the organization's overall security posture using the NIST Cybersecurity Framework (NIST CSF).

## Objectives

- Evaluate existing security controls.
- Identify security risks and compliance gaps.
- Assess the organization's current security posture.
- Recommend security improvements based on industry best practices.

## Skills Demonstrated

- Security Auditing
- Risk Assessment
- NIST Cybersecurity Framework (NIST CSF)
- Security Controls Assessment
- Compliance Assessment
- Documentation
- Risk Analysis

## Repository Structure

- **reports/** – Final security audit report.
- **supporting-documents/** – Original case study documents.
- **documentation/** – Project notes and lessons learned.

> **Note:** This project is based on a fictional case study completed as part of the Google Cybersecurity Professional Certificate.
